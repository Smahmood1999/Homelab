# IT Home Lab Portfolio

## About This Repository

This repository documents my hands-on IT home lab projects focused on system administration, networking, PowerShell automation, Linux, and cybersecurity.

These projects are designed to strengthen my technical troubleshooting, infrastructure management, and automation skills through practical experience.

## Completed Projects

### 1. PowerShell System Health Monitor

Developed a PowerShell script that monitors CPU utilization, available memory, and disk space, generates CSV reports, and displays warnings when system resources fall below defined thresholds.

**Technologies:** Windows 10, PowerShell, WMI/CIM, CSV reporting.

### 2. Windows Service Monitoring Automation

Developed a PowerShell script that monitors Windows services, detects stopped or missing services, and generates timestamped CSV reports.

Tested the monitoring logic using a simulated missing service to verify warning detection and reporting.

**Technologies:** Windows 10, PowerShell, Windows Services, CSV reporting.
